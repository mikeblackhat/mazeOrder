# mazeOrder

A 3D perspective maze game built with HTML, CSS, and vanilla JavaScript. Control the balls using the virtual joystick to guide them to the center of the maze.

## Features

- Interactive virtual joystick controls
- Ball physics and collision detection simulation
- Normal and Hard mode (press `H`)
- Pure HTML5, CSS3, and JavaScript without external libraries

## How to Play

1. Open `index.html` in any modern web browser (or using Live Server).
2. Click and drag the joystick to tilt the maze and guide the balls to the center.
